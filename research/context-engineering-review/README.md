## 目的

コンテキストエンジニアリングに関する主要文献を精読し、専門家向けに公開可能な日本語レビューと、論文横断で再利用できる設計知を蓄積する。

本プロジェクトは、単なる翻訳や論文要約ではなく、次を統合する。

- 原論文の正確な読解
- 技術的背景の解説
- 関連研究上の位置づけ
- 分類・定義・根拠に対する批判的検討
- 実装と運用へ接続できる一般化
- 日本語の用語基盤と技術史の整備

公開原稿では、特定の内部プロジェクトや固有システム名を論証の前提にしない。内部実践から得られた知見は、再利用可能な設計問題、比較軸、運用要件へ一般化する。

## 標準的な作業サイクル

1. 原論文を節単位で読む。
2. 章レビューを公開用Markdownとして書く。
3. 用語集、訳語方針、年表、概念地図を更新する。
4. 書誌情報と参照文献を追加する。
5. 方針文書との整合性を確認し、次章へ進む。

構想の拡張だけで時間を費やさず、章原稿を継続的に完成させる。
