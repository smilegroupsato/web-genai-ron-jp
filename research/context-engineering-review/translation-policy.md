# コンテキストエンジニアリング・レビュー｜訳語方針

- ページ作成日時：2026-07-31 14:20 JST
- 最終更新日時：2026-07-31 14:20 JST

## 目的

本書は、コンテキストエンジニアリング関連文献を日本語で正確かつ読みやすく論じるため、主要用語の訳語と採用理由を記録する。単なる英和対応表ではなく、分野内でまだ定着していない日本語表現を、原語の意味・既存の用例・本文での理解しやすさを照合しながら選定するための基準文書である。

## 基本原則

1. 本文では日本語を優先し、初出時に原語を併記する。
2. 日本語圏で一般化している表記は尊重する。
3. カタカナ語を機械的に増やさず、日本語にすることで意味が明瞭になる語は訳す。
4. 原語との一対一対応が崩れる場合、無理に訳さず原語を併記する。
5. 訳語を変更する場合は、本文・用語集・概念地図を同時に更新する。

## 採用訳語

### Context Engineering

**採用表記：コンテキストエンジニアリング**

「コンテキスト工学」ではなく「コンテキストエンジニアリング」を用いる。日本語圏における現在の用例との連続性を優先し、蒲生弘郷『LLMの原理、RAG・エージェント開発から読み解く　コンテキストエンジニアリング』へのリスペクトを含む。

### Prompt Engineering

**採用表記：プロンプトエンジニアリング**

日本語圏ですでに一般的な表記であり、「プロンプト工学」には置き換えない。

### Context Retrieval and Generation

**採用訳：コンテキスト検索と生成**

Retrieval は本稿の技術的文脈では「検索」と訳す。単なる情報取得一般を指す場合は文脈に応じて「取得」を用いる。

### Context Processing

**採用訳：コンテキスト処理**

### Context Management

**採用訳：コンテキスト管理**

### Assembly

**採用訳：組立**

一般には「アセンブリ」も通用するが、本論文では複数の情報要素を目的に応じて組み合わせる行為を指すため、「組立」のほうが意味を直接伝えられる。

### Assembly Function

**採用訳：組立関数**

### Context Component

**採用訳：コンテキスト構成要素**

### Memory System

**採用訳：メモリシステム**
