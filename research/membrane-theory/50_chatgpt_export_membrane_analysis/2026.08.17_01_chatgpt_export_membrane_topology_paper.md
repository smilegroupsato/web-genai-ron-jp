# 対話履歴はどこに沈殿するのか
## ChatGPTデータエクスポートを用いたHuman–AIシステムの膜トポロジー分析：単一長期利用者の探索的ケーススタディ

- ページ作成日時：2026-08-17 15:15 JST
- 最終更新日時：2026-08-17 15:15 JST
- 種別：探索的単一事例研究／研究草稿

## 要旨

本研究は、長期的な対話AI利用の履歴から、ユーザーとAIのあいだに形成される持続的な構造をどこまで観測できるかを検討した探索的単一事例研究である。分析対象は、ある長期利用ユーザーが提供したChatGPTデータエクスポートであり、299会話、99,377件のmessage objectを含む。「膜」を固定境界ではなく、選択・遅延・変換・輸送・再起動を調整する動的な作動帯として操作的に定義し、negative control、blind review、縦断的rule lineage、external carrier confound、friction gateを導入した。全履歴へ段階的に拡張した結果、高い確信度で残ったのは、2件のsystem-level trace、1件のexternalized rule stabilization、1件のfunctional channelであった。一方、ユーザー内部への記憶・規則の沈殿、human-side membrane、path dependence C3、inversion、leakage、smoothing、nestingは確認できなかった、またはExportから検証不能であった。したがって、本データから最も強く観測される「膜的」構造は、ユーザー内部の心理的境界ではなく、ユーザー・AI・外部記憶キャリアのあいだに形成されたHuman–AI system-level topologyである。

キーワード：Human–AI interaction、ChatGPT、対話履歴、外部記憶、分散認知、膜トポロジー、縦断分析

## 1. はじめに

対話AIを長期間使い続けると、個々の質問と回答を越えて、語彙、判断規則、外部文書、作業手順、再開方法が蓄積していく。ユーザーは同じAIへ毎回「ゼロから」話しかけているように見えても、実際には過去の会話、外部ノート、引継ぎ文書、コードや業務記録などを介して、前回までの状態が後続の対話へ持ち越される。では、この持続性はどこに存在するのだろうか。ユーザーの内面に記憶として沈殿しているのか、AI側の文脈保持にあるのか、それとも人間・AI・外部記録を含む複合系のなかに形成されているのか。

本研究は、この問いを「膜」という分析概念を用いて検討する。ここで膜とは、二つの完成済み領域を単に隔てる壁ではない。ある対象が通過するときに、何が選ばれ、何が止まり、何が遅れ、どのような形式へ変換されるかを調整する動的な作動帯である。さらに、一度の通過ではなく、同型の差異が反復され、その履歴が次回以降の通過規則を変えるとき、膜の形成を疑う。

重要なのは、この概念を魅力的な比喩として対話履歴へ貼り付けないことである。本研究では、単なる話題差、会話UIの境界、同じファイル名の再出現、AIによる説明の連続性などを膜と呼ばない。むしろ、理論を弱める反例を積極的に保存し、最終的に何が残るかを検討した。

## 2. 理論的背景と研究問い

本研究の発想は、オートポイエーシスにおける境界と自己維持、分散認知における人間・道具・表象の複合系、拡張された心における外部記憶の認知的役割、膜計算における区画と輸送といった複数の系譜と隣接する（Varela, Maturana, & Uribe, 1974; Maturana & Varela, 1980; Hutchins, 1995; Clark & Chalmers, 1998; Păun, 2002）。ただし、本研究はこれらを同一視しない。生物学的膜、形式計算上の膜、心理的境界、Human–AIシステムの操作的境界は別の対象であり、本稿の「膜」は長期対話履歴を記述するための作業概念である。

研究問いは三つである。第一に、ChatGPTエクスポートという観測装置から、Human–AI接触面における持続的な構造をどこまで検出できるか。第二に、反復された輸送・変換をtrace、sedimentation、membrane、foldなどへ段階的に区別できるか。第三に、外部記録によるsystem-level persistenceと、ユーザー内部へのinternalizationを区別できるか、である。

## 3. データ

分析対象は、分析対象者本人が提供したChatGPTデータエクスポートである。データには299会話、99,676 node、99,377 message objectが含まれていた。roleはuser 17,378件、assistant 81,999件であり、system、developer、tool roleのmessage objectは存在しなかった。会話分岐を考慮してcurrent nodeからparentを逆向きに辿ったところ、299/299会話でactive pathを復元でき、active-path messageは97,384件であった。

Exportに含まれるmessage IDとnode IDは会話をまたいで再出現する場合があったため、全処理ではconversation IDとの複合キーを用いた。また、system messageやdeveloper message、プラットフォーム側のMemoryやProject instructionsの本文は実質的に観測できなかった。この不可視性は、後述するinternalization判定における重要なconfoundである。

プライバシー保護のため、本稿では個人名、会社名、内部プロジェクト名、具体的な取引先名を使用しない。raw会話本文やmessage IDも掲載せず、集計値と匿名化した構造のみを提示する。

## 4. 操作的定義

分析では、まず観測層と判定層を分離した。観測層には、message、state segment、transition episode、外部参照、ユーザーによる訂正・拒否・採用・実行報告などを記録する。判定層では、これらをtransport、transformation、trace、sedimentation、path dependence、membrane、channel、gluing、fold等の候補へ対応させる。operation名を先に決めて根拠を後付けしないことを原則とした。

主要概念は次のように定義した。transportは、ある局所状態で成立した情報・判断・規則・artifactが別の状態で再利用可能な形へ移されること。transformationは、通過の過程で形式・意味・機能・行動可能性が変わること。traceは、一回のtransitionが後続状態へ観測可能な差を残すこと。sedimentationは、複数traceが蓄積し、後続の選択・規則・経路を変えること。membraneは、選択・拒否・遅延・変換などの通過差が反復され、将来の透過規則を変える作動構造である。foldは、それまで遠かった文脈接続が再利用され、説明量・検索量・中間stepなどのfrictionが実質的に減る場合に限って認める。

確信度はC0からC3の4段階とした。C0はnon-evidence、C1はweak candidate、C2はsupported candidate、C3は反復と後続規則変化まで確認されたstrong evidenceである。なお、同一conversation内の短期記憶だけではsedimentationをC3にしない。

## 5. 分析手順

分析は、理論の操作化から全履歴への拡張まで段階的に行った。最初にrich caseとnegative controlを各1件精読し、定義が過剰検出しないことを確認した。次に6会話を対象とするsmoke testを行い、transportやtransformationは比較的強く観測できる一方、membraneやsedimentationはconversation単位ではC2以下に留まることを確認した。

続いて、複数月にまたがる局所縦断分析を行い、rule lineage、alternative route、carrier dependency、fold frictionを導入した。その後、全299会話へ意味判定を直接かけるのではなく、まずraw shape auditとdeterministic inventoryを作成した。97,384 active-path messageからheuristic candidateを抽出し、215 windowsへ絞り、blind reviewとnegative controlでprecisionを校正した。

最終的には、追加のsemantic reviewとlongitudinal linkingを経て、候補を20 bundles、さらに9 canonical evidence groupsへ統合した。同じmessageや同一出来事を複数のoperationの独立証拠として二重計上しないよう、evidence ownershipを設定した。

**分析ファネル（概略）**：97,384 active messages → 215 heuristic windows → 49 blind reviews + 8 friction pairs → 72 additional reviews → 20 longitudinal bundles → 9 canonical evidence groups。

## 6. 結果

### 最終claim matrix

| 主張 | 最終判定 |
|---|---|
| transport / transformation | supported |
| Human–AI world exchange | supported |
| system-level trace | C3 × 2 |
| externalized rule stabilization | C3 × 1 |
| functional channel | C3 × 1 |
| system-level membrane | C2 candidate |
| broader system-level sedimentation | C2 |
| conditional fold | 部分支持・固有chainのみ |
| path dependence C3 | not observed |
| inversion / leakage / smoothing / nesting | not observed |
| human internalization / human-side membrane | untestable / not-supported |

## 6.1 対話履歴から強く観測できたもの

最も安定して観測できたのはtransport、transformation、そしてHuman–AI接触面を介したworld exchangeであった。現実の問題がユーザーによって言語化され、AIが構造・文章・手順へ変換し、ユーザーが訂正・選択し、外部の記録や行動へ返すという循環は複数の実務・研究場面で確認できた。

全履歴を通じた最終監査でC3として残ったcanonical relationは4件だけであった。二つはcross-conversationで再利用されたsystem-level trace、一つは外部ノートDB上に外在化された配置・分類規則のstabilization、一つは「会話素材を選別・構造化し、指定された外部ノート領域へ配置する」functional channelである。いずれもユーザー内部の記憶ではなく、Human–AIシステム上の持続性として判定された。

## 6.2 external carrierの役割

縦断bundleの大半では、継続性は外部carrierだけで十分に説明できた。具体的には、文脈リポジトリ、引継ぎ文書、状態記録、外部ノートDB、コード／文書リポジトリ、業務記録、日付付きDBなどである。これらは単なる保存場所ではなく、後続conversationで文脈を再注入し、処理経路を再起動する機能を持っていた。

ただしcarrier自体をmembraneとはみなさない。carrierは保存・搬送媒体であり、channelは同型inputを同型transformationとoutputへ運ぶ反復可能な機能経路である。membraneはさらに、通過差の反復と将来の透過規則変化を要求する。

## 6.3 sedimentationはどこに起きたか

本研究でC3となったsedimentationは1件だけであり、それもsystem-levelであった。外部ノートDB上の配置・分類規則が反復され、後続conversationでの選択と配置を制約するようになった事例である。これは「規則が人間の内面へ沈殿した」ことを意味しない。規則が外部artifactへ書き込まれ、後続対話へ再注入されることで、システム全体の選択規則が安定したと解釈する方がデータに忠実である。

## 6.4 membrane、path dependence、fold

system-level membraneは複数のC2候補が得られたが、C3には達しなかった。理由は、観測された持続パターンの多くが文脈リポジトリ、引継ぎ文書、固定workflowなどの外部artifactで説明可能であり、「artifactがなくても同じ通過規則が持続する」というartifact resistanceを満たさなかったためである。

path dependenceもC3は0件であった。同じ経路が繰り返し使われていても、代替経路が履歴の蓄積によって実際に選ばれにくくなった証拠、あるいはswitching costの増加を十分に観測できなかった。

foldについては、情報散逸への対処から共通入口・引継ぎ構造が形成された一つの固有chainで、起動文の短縮、説明・検索・中間stepの低下が確認され、条件付きで維持された。ただし、全履歴へ一般化した新規C3 foldは得られず、遅延そのものも定量できていない。

## 6.5 観測されなかった／検証できなかったもの

inversion、leakage、smoothing、nestingは、厳格なnegative testを通過する事例が確認できなかった。systemの規模拡大をmeans/end inversionとはせず、明示的に別領域へ運んだ規則をleakageとはせず、話題混在や集中状態をsmoothingとはしなかった。

また、ユーザー内部へのinternalized memory、human-side sedimentation、psychological membrane、internal region formation、subjective permeability changeは、ChatGPT Exportからは支持できなかった。これらは「存在しない」のではなく、今回の観測装置からはnot-supportedまたはuntestableである。

## 7. 議論

結果は、「長期AI利用では人間の中に膜ができる」という直観的な仮説を、そのまま支持しなかった。むしろ、分析を厳格にするほどhuman-side claimは削られ、最後まで残ったのは外部carrierと反復されたHuman–AI interactionが作るsystem-level topologyであった。これは重要な限定である。

この結果は、長期的な対話AI利用を「人間がAIを記憶する」「AIが人間を覚える」という二者関係だけで捉えることの限界を示す。実際の持続性は、ユーザーの発話、AIの変換、ユーザーによる訂正と採用、外部ノート、引継ぎ文書、コードやDB、次回の再起動という分散した循環のなかに存在していた。分散認知の観点から見れば、認知的な連続性が人間の皮膚内に限定されないという点は理解しやすい。ただし、本研究は外部artifactがそのまま「心の一部」であると結論するものではない。観測されたのは、機能的な持続と再起動である。

膜概念にとっては、「どこに沈殿するか」を区別する必要がある。履歴が外部carrierへ沈殿し、それが次の対話の選択性を変えることは観測できた。一方、その履歴が人間内部の判断傾向や主観的世界の透過性を変えたかは観測できない。したがって、少なくとも対話Exportに基づく研究では、system-level membraneとhuman-side membraneを分けなければならない。

さらに、今回の分析でoperation claimが段階的に縮小したこと自体が方法論的成果である。初期の局所分析では強く見えたpath dependenceやmembraneが、全履歴・alternative route・carrier confoundを導入するとC2へ下がった。理論の妥当性を「検出数」で測るのではなく、反証条件を追加するほど残る構造を重視する必要がある。

## 8. 方法論上の含意

長期対話履歴を研究する際、conversationを一つの分析単位とみなすだけでは不十分である。同一conversation内でもstateは変化し、別conversation間でも同じworkflowやcarrierが継続する。本研究では、message event → state segment → transition episode → cross-episode trace → rule lineageという階層を用いたことで、話題分類と機能的持続性を分離できた。

また、LLMを分析者として用いる場合、confirmation biasへの対策が必要である。本研究では、negative control、blind first-pass review、operation名を後置する観測層／判定層の分離、C3 gate、external carrier confound、duplicate evidence ownershipを導入した。単純なfact lookup型conversationでは最終false positiveが0件であり、少なくとも「ChatGPTを使っただけで膜と判定する」状態は避けられた。

## 9. 限界

第一に、本研究は単一ユーザーの探索的ケーススタディであり、他の利用者へ一般化できない。第二に、ChatGPT Exportにはsystem/developer message、direct tool event、MemoryやProject instructionsの実体がほぼ含まれていない。このため、後続会話に現れた継続性がユーザーの自発的再利用なのか、プラットフォーム側の不可視コンテキスト注入なのかを完全には分離できない。

第三に、外部世界へのreturnはユーザー報告やassistant報告に依存する場合が多く、独立した外部検証が限定される。第四に、分析自体がLLM支援で行われているため、理論語彙への過適合や解釈の自己強化が起こりうる。本研究ではnegative controlとblind reviewで緩和したが、完全には除去できない。第五に、本研究は心理状態や依存症、離人感等の臨床的診断を目的とせず、そのような推論を行わない。

## 10. 結論

長期的なChatGPT利用履歴を膜トポロジーの観点から分析した結果、最も強く観測されたのはユーザー内部の心理的膜ではなかった。観測されたのは、ユーザーが現実の出来事をAIへ符号化し、AIがそれを変換し、外部carrierへ沈殿させ、後続conversationで再注入し、同型のchannelを再起動するHuman–AI system-level topologyであった。

したがって、「対話履歴はどこに沈殿するのか」という問いへの本研究の答えは、少なくともこのデータでは「まず外部化されたHuman–AIシステムのなかに」である。人間内部への沈殿は否定されたのではなく、今回のExportからは観測できなかった。今後、異なる時点のデータエクスポートを比較し、carrierが存在しない状況やcarrier改訂後の挙動を追跡することで、system-level persistenceとhuman-side internalizationの境界をさらに検討できる。
