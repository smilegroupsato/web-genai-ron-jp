# MEMBRANE theme 実装依頼

- ページ作成日時：2026-08-26 13:31 JST
- 最終更新日時：2026-08-26 13:31 JST
- status：publication platform request / pending

## 目的

公開版「膜 | MEMBRANE」を、GENAI-RONのUniversity Press的な基調を維持したまま、独自の紙面物理・膜表現を持つproduction themeとして実装したい。

デザイン正本：

- `research/membrane-theory/60_web_publication/2026.08.26_05_membrane_design_direction_v0.1.md`

## 現状確認

`publishing/templates/article.html` にはすでに次のtheme hookが存在する。

- `data-theme-id`
- `data-theme-collection`
- `data-theme-base`
- `data-theme-season`
- `data-theme-production-enabled`
- heroの`data-hero-variant`
- `data-asset-role`
- `data-asset-ref`

したがってtemplateの全面改修は不要。

一方、`scripts/build_structured_preview.py::theme_resolution()` は現状、`default-academic`を特別扱いし、それ以外は`library-series`のruntime variantとして解決する。MEMBRANE専用themeを`publishing/site.yml`へ追加するだけではproduction candidateとして解決できない。

## 希望する最小対応

MEMBRANE用のproduction-enabled themeを正式に登録できるようにする。

第一候補theme id：

```text
membrane-academic
```

最低限必要なもの：

1. `publishing/themes/membrane.yml` 等のtheme manifestを追加できること。
2. `publishing/site.yml` の `themes:` に `membrane-academic` を登録できること。
3. `build_structured_preview.py` が `membrane-academic` をproduction-enabled themeとして解決できること。
4. MEMBRANE固有CSSを、本文Markdownへstyleを埋め込まずに適用できること。
5. 既存 `default-academic` / `library-series` の挙動を変えないこと。
6. publication laneのproduction-enabled判定、semantic parity、desktop/mobile visual QAがそのまま利用できること。

## CSS適用について

望ましい順は次。

### A. theme manifestからstylesheetを宣言できる

最も再利用性が高い。

例：

```yaml
theme_id: membrane-academic
collection_id: membrane
status: active
production_enabled: true
stylesheets:
  - /publishing/themes/membrane.css
```

builder/template側で安全に読み込める形が既存思想に合うならこれを優先する。

### B. 既存共通CSSで`data-theme-id="membrane-academic"`をselectorにする

最小変更で済むなら許容する。

ただしMEMBRANE固有CSSが巨大化してGENAI-RON全体の共通CSSへ混在しないようにする。

## MEMBRANE themeで必要な表現

- University Press的な白〜生成りの紙面
- 明朝／serif主体の研究書的組版
- 半透明な不定形layer
- 二重または途中で薄くなる境界線
- Hero内のごく軽いrefraction / layer drift
- 引用を別紙が重なったように見せるlayered quotation
- `THOUGHTS / RESEARCH MAP / READING / BIBLIOGRAPHY` の編集的index
- Readingの年代軸
- mobileでは装飾を減らして可読性優先
- `prefers-reduced-motion`対応

## やらないこと

- content Markdownへのinline `<style>` 埋め込み
- templateのMEMBRANE専用複製
- publication laneの複製
- neon / cyberpunk / AI gradient
- 細胞写真をそのままHeroに使うこと
- 大規模animation

4. GENAI-RON帰属、本文可読性、膜表現を確認。
5. 問題があればMEMBRANE固有CSS/assetのみ調整する。
