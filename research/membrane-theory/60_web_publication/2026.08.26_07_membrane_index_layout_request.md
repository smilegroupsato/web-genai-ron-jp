# MEMBRANE Index Layout Extension Request

- ページ作成日時：2026-08-26 16:48 JST
- 最終更新日時：2026-08-26 16:48 JST
- status：request to publication-platform owner

## 背景

MEMBRANE公開トップは、Visual Target正本

`design/2026.08.26_01_membrane_web_visual_target_v0.1.png`

に合わせ、通常の長文記事ではなく「表紙 + 目次 + 研究地図 + Reading棚 + Bibliography」の研究出版物トップとして構成する。

`content/membrane/index.md` は `page_variant: membrane-index` を持ち、トップ専用contentへ再構成済み。

現行Markdown rendererと共通article templateでは、本文内容は出力できるが、以下を意味のあるDOMとして構成できない。

- Hero内の3入口
- Hero直下Information strip
- THOUGHTS / RESEARCH MAP / READINGのPC三分割
- Bibliography横長帯
- mobileでの意味順を保った縦積み

CSSだけで既存paragraph/h2/tableを無理に並べ替える方法は、content-first設計とsemantic parityを損ねるため採用しない。

## 希望する最小拡張

`page_variant: membrane-index` の場合だけ、MEMBRANEトップ用のsemantic layout/componentを選択できるようにする。

希望するDOM上の領域：

1. `membrane-index-hero`
2. `membrane-index-primary-nav`
3. `membrane-index-information`
4. `membrane-index-grid`
   - `membrane-index-thoughts`
   - `membrane-index-research-map`
   - `membrane-index-reading`
5. `membrane-index-bibliography`
6. `membrane-index-about`

実装方法は既存publication設計に合わせてよい。

優先順位：

- 共通article templateの複製は避ける
- `page_variant`またはpage typeによる限定component解決を優先
- content Markdownへinline HTML / inline styleを要求しない
- MEMBRANE固有CSSは既存`publishing/themes/membrane.css`へ置く
- default-academic / library-series等の出力は変更しない
- production lane / receipt / semantic parity / visual QAを維持

## コンテンツ契約

現段階では、未公開routeへのリンクは生成しない。

THOUGHTS / RESEARCH MAP / READING / BIBLIOGRAPHYは、リンク先が公開されるまでは見出し・非リンク項目として表示できればよい。将来的に公開済みrouteへ段階的にリンクできる構造が望ましい。

Readingは年代軸を維持する。

mobileでは三分割を縦積みにし、順序を以下で固定する。

1. THOUGHTS
2. RESEARCH MAP
3. READING
4. BIBLIOGRAPHY
5. ABOUT

## 非要件

- 動的検索
- WebGL / canvas
- 複雑なscroll animation
- Research Mapの動的可視化
- MEMBRANE専用publication lane
