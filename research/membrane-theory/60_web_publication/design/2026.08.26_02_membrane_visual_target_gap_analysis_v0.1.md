## 1. Purpose

Visual Target正本

`2026.08.26_01_membrane_web_visual_target_v0.1.png`

と、現行production candidateの差分を、実装単位へ分解する。

目標は画像の表面的な模写ではなく、Visual Targetが持つ情報設計、紙面構造、University Press感、膜の横断性をWebとして再現すること。

## 2. Current candidate summary

現行candidateで達成済み：

- `membrane-academic` production theme
- GENAI-RON帰属を保つMEMBRANE専用header
- 半透明layer
- 透過境界・二重線
- layered quotation
- mobile簡略化
- reduced-motion対応
- Markdown `strong` / `blockquote`
- content-first publication laneとの統合

現行candidateは「MEMBRANE固有themeを持つ研究ページ」までは到達している。

一方、Visual Targetは「MEMBRANEという独立研究出版物のトップ／目次」であり、情報設計と紙面構成がまだ不足している。

## 4. Implementation order

### Phase D1 — Top shell

最優先。内容量を増やす前に、トップを「記事本文」から「研究出版物の入口」へ変える。

- [ ] header組版調整
- [ ] Hero高さ圧縮
- [ ] title lockup調整
- [ ] region A / membrane / region B annotation
- [ ] Hero内3入口
- [ ] Information strip
- [ ] desktop三分割shell
- [ ] Bibliography帯shell

この段階ではリンク先が未公開ならdisabled表現または非リンク表示でもよい。ただし公開されていないrouteへのリンクは作らない。

### Phase D2 — Reading shelf

最初に実データを入れる領域としてReadingを優先する。

理由：

- 既存読書ノートが最も充実している
- 年代順という強い視覚軸がある
- University Press / bibliographyの性格と相性がよい
- Topが空のmockupに見えるのを防げる

v0.1候補：

- 1925 Gorter & Grendel
- 1972 Singer & Nicolson
- 1980 Maturana & Varela
- 1987 McHale
- 1991 Varela, Thompson & Rosch
- 2003 Sass & Parnas
- P system / membrane computingの基礎文献

### Phase D3 — Thoughts / Research Map

- [ ] 思索3〜4本をpublic edition化
- [ ] Research Mapの公開版を作成
- [ ] Top三分割へ実データ接続

### Phase D4 — Paper physics refinement

構造完成後に行う。

- [ ] 膜texture assetの調整
- [ ] section横断表現
- [ ] 局所的なboundary drift
- [ ] citation / quotationの別紙感
- [ ] hover時の静かな透過変化

装飾先行は禁止。D1〜D3が成立してから実施する。

### Phase D5 — Mobile

PC版を縮小するのではなく、情報階層を保って再構成する。

- header navは簡略化
- Heroの膜面は1〜2層に減らしてよい
- titleは二段可
- 3カラムは縦積み
- Readingは年代を左軸として維持
- decorative textureは大幅に弱める

## 5. Top page content model

Visual Targetへ寄せるため、`content/membrane/index.md` は長文記事ではなく、トップ専用content modelへ段階的に整理する。

想定ブロック：

1. Hero title / subtitle
2. short thesis
3. primary entrances
4. Information strip
5. Thoughts index
6. Research Map summary
7. Reading shelf
8. Bibliography entrance
9. About / epistemic boundaryへの導線

現在の「膜とは何か」以降の長文本文は、将来的に `/membrane/about/` または独立したThoughtsへ移す候補とする。

## 6. Visual QA criteria

Desktop 1440pxで以下を確認する。

- ファーストビューだけでGENAI-RONとMEMBRANEの親子関係が分かる
- Heroが画面を占有しすぎない
- `膜 / MEMBRANE`が偶然の折返しに見えない
- 膜が背景装飾ではなく二領域の交換面として読める
- HeroからTHOUGHTS / RESEARCH MAP / READINGへ視線が自然に流れる
- 3カラムがブログカードに見えない
- Readingの年代軸が一目で読める
- Bibliographyが独立した出版機能として見える

Mobile 390pxで以下を確認する。

- headerが2行以上に崩壊しない
- Hero titleが読める
- textureが本文を邪魔しない
- section orderがTHOUGHTS → RESEARCH MAP → READING → BIBLIOGRAPHYで保たれる
- 年代と書誌の対応が崩れない

## 7. Non-goals for v0.1

- 完全な検索機能
- 複雑なscroll animation
- 動的なResearch Map
- WebGL / canvasによる膜シミュレーション
- すべての研究資料の公開
- 小説コンテンツの統合
