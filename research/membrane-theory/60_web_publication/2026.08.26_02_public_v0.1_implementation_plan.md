# 公開版「膜」v0.1 実装計画

- ページ作成日時：2026-08-26 12:39 JST
- 最終更新日時：2026-08-26 12:39 JST
- status：implementation plan / not yet published

## 結論

公開版 v0.1 は、`research/membrane-theory/` をそのままWebへ露出するのではなく、公開用Markdown正本を `content/` に作り、既存の new-document publication lane を通して `site/` へ昇格する。

v0.1 の最小完成形は次とする。

- 公開トップ 1ページ
- 研究姿勢 1ページ
- 先行研究地図 1ページ
- 思索 4ページ
- 読書ノート 10ページ前後
- Bibliography 1ページ
- 必要最小限の図版

合計18ページ前後を上限目安とする。

## 1. 公開情報設計

第一候補route：

```text
/membrane/
/membrane/about/
/membrane/research-map/
/membrane/thoughts/exchange-device/
/membrane/thoughts/origin-of-meaning/
```

公開トップの仮タイトル：

**膜 | MEMBRANE**

仮subtitle：

**生命・自己・世界・AIのあいだにあるもの**

トップは「定義集」ではなく、読者が問いへ入れる短い入口にする。

## 2. ページ構成

### P0 `/membrane/`

役割：公開版全体の入口。

内容：

- 暫定定義
- なぜ膜を考えるのか
- 生体膜からAIまでを横断する理由
- 「既存研究」と「膜としての読み」を区別する宣言
- Thoughts / Research / Reading への導線

source：

- `README.md`
- `10_theory/2026.08.01_01_human_membranes_concept_note.md`
- `40_observations/2026.08.03_05_membrane_joucho_first_response.md` の定義形成部分

### P1 `/membrane/about/`

役割：研究姿勢・免責ではなく epistemic boundary を示す。

内容：

- 領域横断研究であること
- 生物学的膜と心理・AIの「膜」を同一視しないこと
- 既存研究／佐藤の読解／作業仮説／創作的転用の区別
- 現段階は完成された学術理論ではないこと

source：`CHARTER.md`

### P2 `/membrane/research-map/`

役割：先行研究の見取り図。

軸：

```text
生体膜
  ↓
自己産出・オートポイエーシス
  ↓
身体性・enaction・意味生成
  ↓
自己経験・現象学・精神病理
  ↓
境界・世界・存在論の文学
  ↓
AI対話・履歴・コンテクスト
```

source：`20_research/2026.08.01_03_membrane_prior_research_map.md`

### T1 「膜は境界ではなく交換装置である」

公開版の最重要短論考。

扱うもの：選別、透過、遅延、変質、調整、履歴による膜自身の変化。

### T2 「意味はどこから生まれるのか」

Varela / Thompson / Rosch とオートポイエーシス読解を足場に、生命・身体・差異・意味生成を考える。

重要：既存研究が「意味は生命と同時に生まれる」とそのまま主張している、と誤認させない。これは佐藤側の問い・仮説として分ける。

### T3 「膜・主体・トポロジー」

region / membrane / nesting / fold / inversion / leakage / smoothing のうち、公開読者に必要な概念だけに絞る。

source：`10_theory/2026.08.03_06_membrane_space_topology_spec_v0.md`

### T4 「履歴はどこに沈殿するのか」

AIとの対話履歴が、人間・モデル・外部記録・次の会話へどう分散して残るかを考える。

source：

- `50_chatgpt_export_membrane_analysis/notes/2026.08.17_01_where_dialogue_history_sediments_literary_note.md`
- ChatGPT Export分析成果のうち検証済み部分

## 3. Reading セクション

読書ノートは原文を一括コピーしない。各ページを共通構造に整える。

推奨構造：

```text

この文献は何をしたか
重要な概念
膜を考える上で何が重要か
ここから先は佐藤の読解

```

- Singer & Nicolson (1972)
- Nicolson (2014)

第2陣：

- Varela, Thompson & Rosch (1991)

第3陣：

- Blankenburg (1971)

- Parnas & Sass (2011)
- Sierra (2009)

第4陣：

- McHale (1987)
- Pynchon (1973) はv0.1後半またはv0.2へ回してよい

## 4. Bibliography

- 分野タグ

## 5. Visual

v0.1で図を増やしすぎない。

優先候補：

1. 「膜の基本動作」：region A / membrane / region B、選別・変質・双方向交換
2. 「先行研究地図」：分野間を同一視せず接続する図
3. ChatGPT Export分析で作成済みの日本語SVGのうち、本文とclaim boundaryが一致するもの

既存の `50_chatgpt_export_membrane_analysis/visualization/figures/*_ja.svg` は、そのまま採用せず本文確定後に再審査する。

## 6. `content/` 側の実装方針

専用source root候補：

```text
content/membrane/
  index.md
  about.md
  research-map.md
  thoughts/
  reading/
  bibliography.md
```

ただし、既存 `new_document_publication.py` がstandalone文書単位のroute registryを前提としているため、実装開始前に `content/membrane/` の階層が現行validatorで問題なく扱えるか確認する。

無理に既存仕組みを壊さず、必要なら各文書を既存 `content/notes/` 等へ置くのではなく、publication laneを最小拡張して `/membrane/` namespaceを正式対応させる。

## 7. publication laneとの接続

既存 `publishing/NEW_DOCUMENT_PUBLICATION.md` に従う。

各公開Markdownには必須metadataを付与する。

- id
- title
- subtitle
- description
- slug
- canonical_url
- theme_id
- status: publication-candidate
- page_created_at
- last_updated_at

公開までの基本経路：

```text
60_web_publicationで選定・編集方針確定
    ↓
content/membrane/ にpublic edition作成
    ↓
data/new-document-routes.json 登録
    ↓
index正本へ導線追加
    ↓
new_document_publication.py prepare
    ↓
desktop / mobile visual QA
    ↓
明示昇格
    ↓
site/ + route manifest
```

## 8. 実装フェーズ

### Phase 0：公開境界固定

完了条件：

- A/B/C棚卸しがある
- 非公開範囲が明示されている
- route案が決まっている
- source archiveとpublic editionを分ける方針がある

現状：ほぼ完了。

### Phase 1：最初の3ページを原稿化

対象：

1. `/membrane/`
2. `/membrane/about/`
3. `/membrane/research-map/`

目的：大量の読書ノートを先にWeb化せず、サイトの意味・語彙・境界を固定する。

### Phase 2：Thoughts 4本

公開版「膜」の独自性が見える層を作る。

この段階で、「膜」という語が単なる万能比喩に見えないかを再点検する。

### Phase 3：Reading 第1陣

生体膜3本を先に公開する。

理由：比喩から始まったように見せず、膜という物理的・生物学的対象の歴史から入れるため。

### Phase 4：Reading 第2〜3陣

オートポイエーシス／身体性／現象学／精神病理へ広げる。

各ページで「この文献そのものの主張」と「膜としての読解」を視覚的にも節として分ける。

### Phase 5：Bibliography・cross-link・visual

- 関連ページリンク
- bibliography
- glossary的補助
- 図版
- OGP / description
- mobile QA

### Phase 6：v0.1 freeze

公開後に研究sourceが増えても、v0.1本文を無制限に追記しない。

大きな概念変更は v0.2 へ送る。

## 9. 実装前に確認する技術項目

- `/membrane/` namespaceを既存route registryが扱えるか
- `content/membrane/` を現行build / validationが走査対象にできるか
- site header / indexから新しいトップレベル領域へ導線をどう置くか
- 既存themeで十分か、膜専用themeが必要か
- SVGの配布場所とbuild時コピー規則
- sitemap / manifestへの追加が自動化されるか
- new-document laneでindexページそのものを作れるか

ここで問題が出た場合のみ publication基盤を変更する。

## 10. v0.1でやらないこと

- research directoryの自動公開
- chat log viewer
- self-test公開
- 小説本文の同時公開
- 大規模検索UI
- DB化
- 全文献の一括公開
- 「膜理論」を完成した統一理論として提示すること
- 個人的体験を医学的エビデンスとして扱うこと

## 11. 完成条件

v0.1完成はページ数ではなく、次で判断する。

1. 初見の読者が「膜」という語の暫定定義を理解できる。
2. 生物学からAIまでをなぜ横断するのか説明できている。
3. 既存研究と佐藤の仮説が区別されている。
4. 少なくとも生体膜・自己産出・身体性・自己経験・文学・AIの入口がある。
5. 読書ノートから中心論考へ戻れる。
6. 個人的観測や生ログが不用意に露出していない。
7. mobile / desktopで読める。
8. publication lane・manifest・sitemapが整合している。

## 次の実作業

次は Phase 1 として、次の3つを行う。

1. `content/membrane/` が現行publication基盤で扱えるか技術確認する。
2. 公開トップ「膜とは何か」のpublic edition草稿を `60_web_publication/` 内で先に作る。
3. 草稿確定後にだけ `content/` へ昇格候補を作る。

この段階では `site/` へ直接書かない。
