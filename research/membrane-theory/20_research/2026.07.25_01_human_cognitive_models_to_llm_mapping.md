## 0. 位置づけ

この文書は、Wang et al. (2024) の Solo Performance Prompting（SPP）論文を読解し、その発想、実験、限界、近接研究を整理した研究ノートである。

SPPは、一つのLLMに複数のペルソナを動的に作らせ、複数ターンの自己協働を演じさせる手法である。論文読解から派生して、本ノートでは、人間の知性・認知・心理について作られた既存モデルをLLM上の操作形式へ移す「人間からLLMへの写像問題」をOpen Questionとして残す。

## 1. 論文の中心的な試み

SPPが行うことは、概ね次の三段階である。

1. 課題に必要な複数のペルソナをLLM自身に選ばせる。
2. 各ペルソナに異なる観点から情報、案、批評を出させる。
3. リーダー役がそれらを統合し、回答を修正する。

一つの基盤モデルの中で、起案、専門確認、批評、統合を順番に生成する。

## 2. 佐藤の評価

一つのAIに複数役を演じさせ、内部で相談・批評・統合を行わせる発想そのものはよい。

ただし、論文は成績評価や既存手法との比較に重心があり、学校的でつまらない。使われる「認知的シナジー」「創発」などの言葉も、実験から確認できたこと以上に大きく見せている。明確な機構や強い結果が得られたとは言い難い。

現時点の評価は、**大発見ではなく、やってみたことには価値がある程度**である。後続研究を決定的に方向づけたエポックメイキングな研究というより、複数ペルソナ・内部討議系の研究で参照される一つの名前付き手法、比較基準になったと見るのが妥当である。

本当に面白い問いは、正答率が上がったかではなく、次である。

> 一つの生成系の中に複数の声を立ち上げたとき、それらはどこまで別々でいられるのか。

## 3. 著者らは、なぜこれをしようと思ったのか

論文の導入から読むと、発想の源は次の四つに整理できる。

1. 人間は一人で考えるだけでなく、異なる人間や異なる認知過程を組み合わせて問題を解くという「協働」への着目。
2. 子どものごっこ遊び・役割遊びが認知発達に関係するという発達心理学からの着想。
3. LLMに専門家や人物像などのペルソナを与えると、特定の知識や振る舞いが引き出されるという先行研究。
4. 複数の独立LLMエージェントを動かすと費用がかかり、役割も固定されやすいため、単一LLM内で必要な役を動的に作れないかという実装上の動機。

出発点は、次の素朴な着想である。

> 複数AIを接続する代わりに、一つのLLMを複数人のように振る舞わせれば、安価に協働を模倣できるのではないか。

問題は、その着想を「認知的シナジーの創発」という大きな概念に持ち上げた一方で、実験は限定された課題に留まり、内部で本当に異なる認知主体が成立したことは示していない点にある。

## 4. Chain-of-Thoughtとは何か

Chain-of-Thought（CoT、思考の連鎖）は、LLMに答えだけを出させず、答えに至る途中の推論手順を文章として生成させるプロンプト手法である。

- 通常：質問 → 答え
- CoT：質問 → 手順1 → 手順2 → 手順3 → 答え

元の研究では、途中の推論例を数件プロンプトに示す方法が使われた。後に「Let’s think step by step（順を追って考えよう）」と添えるZero-shot CoTも提案された。

重要なのは、CoTがモデル内部の本当の思考を直接読み出しているわけではないことである。生成された途中説明は、問題解決に役立つ作業用テキストにはなりうるが、内部計算そのものの透明な記録とは限らない。

SPPとの違いは次の通りである。

- CoT：一つの声の中で推論手順を延ばす。
- SPP：複数の役を作り、発言、批評、統合を演じさせる。

膜理論の言葉で言えば、CoTは一本の生成線を長くする方法であり、SPPは一つの生成の中に仮の区画を作る方法である。

## 5. 同様・近接する研究

### SPP以前または同時期

- **Self-collaboration Code Generation via ChatGPT（2023-04）**
  - analyst、coder、testerなどを演じ分け、単一の基盤モデルによる仮想開発チームを作る。SPPより早く、用途はコード生成に限定される。
- **CAMEL（2023-03）**
  - 複数の会話エージェントへ役割を与え、自律協働させる。発想は近いが、単一チャット内部の一人複数役というより複数エージェント構成である。
- **Multiagent Debate（2023-05）**
  - 複数モデルの回答を討論させるsociety of minds型。独立した複数インスタンスを使う。
- **Encouraging Divergent Thinking through Multi-Agent Debate（2023-05）**
  - 賛成役、反対役、審判役などを置き、自己反省が同じ考えに固着する問題を破ろうとする。

### SPP以後

- **Meta-Prompting（2024）**
  - メタ役が課題に応じて専門家役を呼び出し、回答を統合する。SPPを比較対象として明示する。
- **Multi-expert Prompting（2024）**
  - 一つの生成過程の中で複数専門家をシミュレートし、意見を集約・選択する。SPPに近い後続研究である。
- 2024年以降のロールプレイLLM、マルチエージェント討論、推論時自己改善のサーベイや応用研究で、SPPは一つの代表例として参照されている。

SPPは孤立した思いつきではない。2023年前後に、自己批評、複数推論経路、討論、役割分担、仮想エージェント社会が同時多発的に現れた。その中でSPPが付け加えたのは、課題ごとに役を動的に選び、一つのLLM内で複数ターンの協働を完結させる一般プロンプトとして整理したことである。

Chain-of-Thoughtのように分野全体の基本語彙や標準手法を変えたとは言いにくい。現時点では、**一つのAIの内部に複数の役割区画を作る研究系譜の初期ノードの一つ**と評価する。

## 6. 人間の認知モデルをLLMへ移す研究として読む

この種の研究の基本形は、次である。

1. 人間について作られた知性、認知、心理のモデルを選ぶ。
2. それをLLM上のプロンプト、Role、発話順序、状態、権限、通信形式へ置き換える。
3. 通常の生成方法と比較し、出力性能に有意差が出るかを測る。
4. 差が出た場合、元の人間概念を使って説明する。

SPPの場合は、人間の複数者協働、役割遊び、認知的シナジーを、一つのLLM内の複数ペルソナと反復的な自己協働へ移している。

しかし、再現しているのは人間の認知現象そのものではない。再現しているのは、人間の認知モデルを参考にしたLLM上の操作形式である。

人間の集団には、別々の身体、経験、記憶、感情、利害、可視範囲、拒否可能性がある。SPPのペルソナは、同じモデル、同じ重み、同じContext、同じ生成系列を共有する。

したがって、次の三つを分ける必要がある。

- **着想源**：人間の認知・心理モデル
- **実装物**：プロンプト、Role、エージェント構成、状態管理
- **観測結果**：回答精度、評価値、失敗形式の変化

この三者の間には距離がある。有意差が得られたことだけでは、元の人間概念がLLM内部に存在することは示されない。

## 7. 人間→LLM写像問題

この問題は、次の写像として記述できる。

```text
Human Cognitive / Psychological Model
                ↓ mapping
LLM Interaction / Agent Architecture
```

人間側の要素は、LLM側で次のように置換される。

| 人間側 | LLM側の候補 |
| --- | --- |
| 複数主体 | 複数Role、複数インスタンス、複数state machine |
| 身体差 | 異なる入力チャネル、ツール、環境接続 |
| 経験差 | 異なる履歴、Context、検索結果、memory store |
| 記憶の分離 | 個別state store、可視範囲制御 |
| 利害・感情 | 目的関数、優先順位、評価規則、制約 |
| 対話・説得 | message passing、debate、review、handoff |
| 権限差 | read/write/approve/reject権限 |
| 社会的境界 | interface、access control、通信プロトコル |

この置換は同一性ではない。人間側の構造を削減、変形、再符号化したものである。

## 8. 膜理論との接続

SPPのペルソナは、名前を付けた発話役に近く、明確な膜ではない。各役は同じモデル、同じ文脈、同じ知識、同じ生成系列を共有している。

膜として考えるなら、単なる役名ではなく、各区画に次を持たせる必要がある。

- 参照できるContextの範囲
- 他のRoleから見えない情報
- 発言権、決定権、拒否権
- Roleの持続時間と終了条件
- 他のRoleから受ける影響の強さ
- 情報を通す／通さない選択的透過性
- 統合役が差異を消さないための規則
- 個別の履歴と状態遷移

このとき問題は、何人のペルソナを出せば点数が上がるかではない。

> 一つの生成系の内部に、どの程度まで本当の差異、距離、非対称性を作れるか。

内部膜型A2Aとの接続では、SPPは「修辞的膜」または「手続的膜」の初期例として位置づけられる。構造的な膜へ進むには、Context、state、権限、通信経路の分離が必要になる。

## 9. Open Question：人間からLLMへの写像問題

### 中心問い

> 人間の知性・認知・心理モデルをLLM上の構造へ写像するとき、何が保存され、何が失われ、何が変形され、何が新たに生じるのか。

### 個別の問い

- 人間の認知モデルのどの構造がLLMへ写像可能か。
- 写像において保存すべきものは、機能、関係、因果、時間構造、境界のどれか。
- 人間側の身体性、情動、利害、有限性は、LLM側で何に対応するか。
- 同じ名前の概念を使用することで、比喩と機構を混同していないか。
- 有意差が得られたとき、元の認知モデルの妥当性と、単なるプロンプト効果をどう区別するか。
- 人間モデルをLLMへ移した結果、元のモデルにはなかったLLM固有の構造が生じるか。
- 役ごとに異なるContextを与えた場合、それは単一AI内の内膜か、実質的な複数エージェントか。
- 役の数より、膜の透過性、権限、記憶分離の方が重要ではないか。
- 統合役を置かず、複数の声が未統合のまま共存する設計は可能か。
- 内部対話は能力向上技術ではなく、主体、著者性、責任の輪郭を変える装置として研究できるか。

## 10. 暫定評価

SPP論文の価値は、人間の認知的シナジーをLLMで再現したことにはない。

その価値は、単一LLM内で複数役を動的に作り、反復的な自己協働を行わせる一般形式を、明示的な実験対象として提示したことにある。

そこから派生する重要な研究課題は、ベンチマーク成績ではなく、人間の認知モデルとLLM構造の間にどのような写像を定義できるか、その写像が何を保存し、何を破壊するかを調べることである。
