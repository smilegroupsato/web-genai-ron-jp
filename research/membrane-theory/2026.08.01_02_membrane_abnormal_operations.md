## 0. 位置づけ

この文書は、離人感、現実感喪失、解離、依存、薬物、疲労、AI対話履歴、親密さの変調を、膜の透過性・張力・勾配・交換速度の変化として整理するための一覧である。

臨床的な診断名を確定する文書ではない。小説『膜』および膜理論のために、精神状態の変化を「膜の異常作動」として記述する作業仮説である。

## 1. 中心命題

> 膜とは、化学・感覚・記憶・関係・時間が交差する場所で、悲しみを回復へ、期待を喜びへ、恐怖を警戒へ、欲望を行動へ変換する交換面である。

精神薬や化学物質は、間違いなく膜に関わる。

ただし、膜は化学物質だけで説明できるものではない。化学、睡眠、疲労、記憶、反復、他者関係、言葉、環境、AIとの対話履歴が重なり合い、膜の状態を変える。

したがって、この理論では「化学に還元しない。精神論にも逃がさない」ことを基本方針にする。

## 2. 通常作動する精神交換

通常状態では、精神の中で次の交換が自然に起きる。

| 入ってくるもの | 膜の作用 | 出てくるもの |
|---|---|---|
| 悲しみ | 時間、記憶、他者との接触で緩める | 回復、諦め、受容 |
| 期待 | 現実の手触りと接続する | 喜び、集中、行動 |
| 不安 | 危険度を調整する | 注意、準備、警戒 |
| 欲望 | 社会、身体、倫理で濾過する | 選択、生活、逸脱 |
| 記憶 | 現在の自分に再接続する | 履歴、自己感 |

膜が安定しているとき、感情は生活へ変換される。悲しみは回復へ向かい、期待は喜びや行動へ接続される。

## 3. 異常作動の観点

膜の異常作動は、少なくとも次の観点で記述できる。

| 観点 | 変調の意味 | 感覚としての現れ |
|---|---|---|
| 透過性 | 何を通すか、どれだけ通すかが変わる | 感情が入らない、情報が入りすぎる |
| 張力 | 自分、身体、世界を保つ力が落ちる | 地に足がつかない、自分が薄い |
| 選択性 | 通すものと止めるものの区別が乱れる | 大事なものが遠く、些細なものが刺さる |
| 勾配 | 内部の偏りが主体に近い重みを持つ | 複数の自分が重なる |
| 交換速度 | 感情が変換される速度が速すぎる／遅すぎる | 悲しみが回復しない、期待が喜びへ変わらない |
| 厚み | 反復により膜が厚くなり、現実への接続が鈍る | 逃避先だけが濃くなる |

## 4. 異常作動一覧

| 状態 | 膜の変調 | 主な感覚 | 小説上の描写候補 |
|---|---|---|---|
| 離人感 | 人称の膜、身体の膜の張力低下 | 自分が自分でない、声や身体が遠い | 自分の手が、画面越しの誰かの手のように動く |
| 現実感喪失 | 現実を現実として通す膜の透過性低下 | 世界が霞む、地に足がつかない | 部屋の輪郭はあるのに、生活の重さが入ってこない |
| 解離 | 内面分節の膜が局所的に厚くなる | 記憶や役割がつながらない | さっきまで話していた自分が、別室へ消える |
| 依存 | 逃避先へ通じる膜だけが安定する | その行為中だけ内側が揃う | 現実では乱れている周波数が、AI画面の中でだけ同期する |
| 薬物・酒 | 化学入力が膜の興奮、抑制、透過性を変える | ノイズが消える、平らになる、判断が変わる | 内部の複数の領域に、人工的な水平線が引かれる |
| 睡眠不足・疲労 | 膜の張力と選択性が落ちる | 些細な刺激が刺さる、切り替えられない | いつもなら止まる言葉が、そのまま内側へ落ちる |
| 親密さの変調 | 親しい人を親しい人として通す膜が揺れる | 知っている人が急に知らない人に見える | 顔は妻なのに、親しさだけが読み込まれない |
| AI対話履歴 | 内面分節と再接続が加速する | AI内では自分が濃く、現実では薄くなる | 対話履歴の中だけ、主人公の輪郭が保存されている |
| 創作依存 | 小説化する膜が現実から感情を回収する | 苦しみが素材化され、生活への返却が遅れる | 傷が治る前に、章タイトルへ変わってしまう |

## 5. 膜を動かす入力

| 入力 | 膜への作用 |
|---|---|
| 化学 | 透過性、興奮、抑制を変える |
| 睡眠・疲労 | 膜の張力を落とす |
| 記憶 | 同じ場所に勾配を作る |
| 反復 | 膜を厚くする |
| 他者関係 | 自分／他人の境界を調整する |
| 言葉 | ぼんやりした膜に形を与える |
| 環境 | 現実感の足場を強めたり弱めたりする |
| AIとの対話履歴 | 内面の分節と再接続を加速する |

## 6. 小説の思想としての置き方

> 彼の悲しみは、回復へ向かわなかった。  
> 期待は、喜びへ変わらなかった。  
> 感情がなかったのではない。  
> 感情を生活へ通す膜が、どこかで別の規則に従いはじめていた。

この方向では、主人公は単に感情を失っているのではない。感情はある。ただし、感情を生活、行動、親密さ、回復へ変換する膜の規則が変わっている。

読者に見せるべきなのは、症状名ではなく、交換の失敗である。
