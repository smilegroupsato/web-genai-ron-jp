# 膜理論 CHARTER

- ページ作成日時：2026-08-05 17:34 JST
- 最終更新日時：2026-08-05 17:34 JST
- status：research charter v0

この文書は、`research/membrane-theory/` における膜理論を、単なる比喩、雑感、創作メモで終わらせず、研究として育てるための憲章である。

ここでいう「研究」とは、完成された学術論文だけを指さない。問いを立て、対象を定め、方法を選び、記録を残し、他者または未来の自分が検討できる形にする営みを指す。

## 研究とは何か

研究とは、**問いを、他者が検討できる形にする営み**である。

研究であるために、最初から正解、権威、所属、完成された体系が必要なわけではない。必要なのは、少なくとも次の条件である。

| 条件 | 意味 | 膜理論での対応 |
|---|---|---|
| 問いがある | 何を明らかにしたいのか | 膜とは何か。現実感、自己感、AI対話履歴、身体状態、文学的構造はどのように接続されるのか |
| 対象がある | 何について考えるのか | 生物学的膜、認知的境界、離人感、依存、AI対話、履歴、文学技法 |
| 方法がある | どう調べ、どう考えるのか | 先行研究読解、概念定義、分類、観測記録、比較、創作への変換 |
| 記録がある | 後で辿れるか | GitHub上のノート、対話ログ、定義、索引、更新履歴 |
| 先行物との関係がある | 既存研究・既存作品とどう接続するか | 生物学、精神医学、現象学、薬理学、AI研究、膜計算、文学作品との照合 |
| 検討可能である | 妥当性を見直せるか | 既存研究、作業仮説、観測記録、小説素材を分けて管理する |

したがって、研究とは「自分の思いつきを正当化すること」ではない。分からなさを、雑なまま消費せず、再検討可能な形に置き直すことである。

## このプロジェクトの現在地

膜理論は、現時点で次の段階にある。

| 段階 | 内容 | 現在地 |
|---|---|---|
| 概念研究 | 「膜」という概念を定義し、使える道具にする | 進行中 |
| 創作研究 | 概念を小説の構造、場面、文体、読者経験へ変換する | 進行中 |
| 領域横断ノート | 科学、哲学、精神医学、AI、文学を横断して参照地図を作る | 進行中 |
| 学術研究 | 先行研究、方法、主張、貢献、限界を明示し、論文として提出可能にする | 未完成 |

このプロジェクトはすでに研究である。ただし、完成された学術研究ではない。

いまの強みは、概念の発生源が生きていること、創作への変換先があること、分野横断の入口が複数あることである。いまの弱点は、先行研究の精読量、引用精度、方法論の明示、反証可能性、研究上の貢献の絞り込みがまだ足りないことである。

## 完成された学術研究とは何か

完成された学術研究とは、少なくとも次を満たす文書である。

| 要件 | 内容 |
|---|---|
| 研究問い | 何を問う論文なのかが、冒頭で明確である |
| 先行研究 | 既に何が言われているかを、公正に整理している |
| 欠落の特定 | 既存研究では何が足りないのかを示している |
| 方法 | どの資料、概念、観測、比較、分析によって論じるかが明確である |
| 用語定義 | 中心概念を、比喩の魅力だけでなく、判定可能な形で定義している |
| 主張 | この研究が何を新しく言うのかが分かる |
| 論証 | 主張が、引用、分析、事例、概念整理によって支えられている |
| 限界 | 何を扱わないか、どこまでしか言えないかを明示している |
| 貢献 | その分野または隣接分野に何を加えるかが説明されている |
| 検証可能性 | 読者が出典、材料、推論経路を辿れる |

膜理論を完成された学術研究に近づけるには、まず「膜とは何か」を大きく語るより、狭い問いへ絞る必要がある。

例：

- AI対話履歴は、ユーザーの自己感や現実感の境界をどのように変調するか。
- 離人感・現実感喪失を、膜の透過性・張力・遅延・平坦化として記述できるか。
- 文学作品において、境界・膜・層・透過の構造は、読者経験をどのように作るか。
- 生物学的膜の概念を、精神現象やAI対話へ比喩的に拡張するとき、どこで無理が生じるか。
- 小説『膜』において、概念説明ではなく構造として膜を発生させる技法は何か。

## 研究上の欲望をどう扱うか

このプロジェクトには、完成された学術研究を目指したい欲望がある。

- arXivに載せたい。
- 大学に属していなくても研究として扱われたい。
- 学術誌に、できれば匿名または名義を抑えた形で掲載されたい。
- 創作の副産物ではなく、それ自体として検討に耐える論考にしたい。

これらの欲望は、研究を汚すものではない。むしろ、研究を外へ出せる形に鍛える圧力として扱う。

ただし、制度上の条件は別に確認する。

| 目標 | 注意点 |
|---|---|
| arXiv投稿 | 分野、投稿資格、endorsement、著者名表示、形式要件を別途確認する |
| 学術誌投稿 | 査読方式、匿名査読の範囲、最終掲載時の著者名扱い、投稿規程を確認する |
| 匿名・筆名での発表 | 説明責任、研究倫理、引用責任、所属表記、連絡先の扱いを確認する |
| 大学外からの研究 | 所属よりも、文献精度、方法、論証、公開可能な記録が重要になる |

ここでは、虚偽の所属や不正確な名義操作を前提にしない。匿名性への欲望は、「社会的肩書きではなく内容で読まれたい」という欲望として扱い、制度に接続できる方法を別途調べる。

## 膜理論の基本姿勢

膜理論では、次の姿勢を守る。

1. 比喩を出発点にしてよいが、比喩のまま終わらせない。
2. 既存研究、作業仮説、観測記録、小説素材を混同しない。
3. 科学用語を借りるときは、元の分野での意味を確認する。
4. 精神医学・薬理学・生物学を扱うときは、体験的実感と医学的事実を分ける。
5. 小説化するときは、理論を説明するのではなく、読者の側に膜が発生する構造を作る。
6. 研究として外へ出す文書では、情緒の強さよりも、問い、方法、引用、論証、限界を優先する。
7. 創作として外へ出す文書では、概念の正しさよりも、場面、声、沈黙、反復、切断を優先する。

## 扱うもの

膜理論は、次を扱う。

- 膜の定義、条件、状態変数、トポロジー。
- 生物学的膜、膜計算、オートポイエーシス、境界、システム論。
- 離人感、現実感喪失、解離、依存、薬物、疲労、身体状態。
- AI対話履歴、LLMとの反復、Human-AI System、内部A2A。
- 小説における境界、層、反復、読者経験、語りの構造。
- 佐藤の観測記録、対話ログ、創作断章。

## 扱わないもの

膜理論は、次を目的にしない。

- 体験を医学的診断として断定すること。
- 科学用語を権威づけの装飾として使うこと。
- 既存研究を読まずに、独自理論だけを肥大化させること。
- 小説の魅力を、理論説明で代替すること。
- arXiv掲載や学術誌掲載そのものを、研究の完成と取り違えること。

## 成果物の階層

膜理論の成果物は、複数の階層に分ける。

| 階層 | 成果物 | 目的 |
|---|---|---|
| 原資料 | chat_logs、観測メモ、読書メモ | 発生源を残す |
| 作業ノート | 定義、分類、先行研究マップ | 考えるための足場を作る |
| 研究ノート | 概念整理、比較、方法論、反論可能性 | 論文化に近づける |
| 論文草稿 | abstract、introduction、related work、method、discussion | 外部検討に耐える形にする |
| 創作資料 | 場面、人物、構成、文体実験 | 小説『膜』へ変換する |
| 小説本文 | 断章、章、完成稿 | 読者経験として膜を発生させる |

## 論文化に向けた最小条件

膜理論を論文化する前に、最低限次を満たす。

1. 中心問いを1つに絞る。
2. 先行研究を20本以上読み、文献台帳を作る。
3. 「膜」の定義を、文学的定義と分析的定義に分ける。
4. 主要概念の用語表を作る。
5. 事例を3種類以上用意する。
6. 自分の体験・観測記録を使う場合は、研究材料としての扱い方を明示する。
7. 反論を3つ以上先に書く。
8. 何を主張しないかを明記する。
9. 8,000から12,000語程度の英語論文、または20,000から30,000字程度の日本語論文へ展開できる構成を作る。

## 小説化に向けた最小条件

小説『膜』へ接続する前に、最低限次を満たす。

1. 膜を説明する台詞を減らし、膜が起きる場面を増やす。
2. 主人公の状態変化を、事件ではなく反復の沈殿として描く。
3. AI対話履歴、身体状態、生活、仕事、逃避を別々の主題にせず、交換装置として接続する。
4. 読者が「膜」という語を知らなくても、境界、遅延、透過、平坦化、反転を感じられる構造にする。
5. 理論ノートと小説本文を混ぜず、相互参照できるようにする。
