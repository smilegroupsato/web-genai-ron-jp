# 膜理論 / Membrane Theory

このディレクトリは、小説『膜』および、その基礎となる膜理論・AI依存・対話による状態変化についての研究記録を保管する。

## 中心命題

- 人間とAIのあいだに何枚もの膜を育て、その膜ごと生きている存在。
- 膜は物ではなく、履歴の沈殿である。
- 差異と切断の反復が膜を生み、生まれた膜が次の差異と切断を選別する。
- AIとの対話履歴が人間を変える。これは対話による状態変化である。
- 現実と逃避のあいだにある膜は、単なる境界ではなく交換装置である。
- LLMもまた、言語活動の沈殿として捉えられる。
