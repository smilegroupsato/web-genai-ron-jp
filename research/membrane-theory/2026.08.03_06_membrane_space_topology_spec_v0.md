## 0. 目的

この文書は、小説『膜』を書く前に、作品世界で一貫して働く「膜空間」のトポロジーを規定するための仕様 v0 である。

ここでいうトポロジーは、数学の位相幾何学をそのまま小説へ移植するものではない。距離や時系列ではなく、**何が近いか、何が通じるか、どこを越えると表裏・内外・主体/道具・実務/逃避が反転するか**を扱うための規則である。

物語ジャンルは、経済小説、犯罪小説、恋愛小説、家族小説、AI依存小説のいずれでもよい。ただし、どの題材であっても、出来事を通じて膜空間の複雑な接続規則が立ち現れることを条件とする。

## 2. 基本定義

### 2.1 膜

**膜**とは、内外を隔てる素材ではなく、差異が反復され、沈殿し、選択・遅延・変質・交換・信号化が起こる動的な作動帯である。

膜はサランラップのような固定された薄いシートではない。生物学的膜が、分子の流動、受容体の局在、チャネル、キャリア、信号伝達、膜輸送によって働くように、膜理論の膜も「境界そのものが働いている場所」として扱う。

中心定義：

> 膜とは、世界が分かれる場所ではなく、世界の分かれ方が発生する場所である。

### 2.2 膜空間

**膜空間**とは、複数の region と、それらの間に働く膜、勾配、輸送、折り畳み、反転、貼り合わせによって構成される文脈的・身体的・社会的・物語的な空間である。

膜空間では、物理的距離や時系列の近さよりも、文脈が届く範囲、責任が伝わる範囲、痛みが入ってくる範囲、言葉が意味を持つ範囲が重要になる。

### 2.3 region

**region** は、文脈・人格・実務・AI対話・身体感覚・記憶・役割・逃避行為などが、一時的にまとまって働く局所領域である。

region は固定された部屋ではない。反復と沈殿によって、ある語彙、反応速度、透過条件、記憶、身体感覚がまとまり、他の region と区別できるようになった領域である。

例：

- 仕事を考える region
- 家庭に反応する region
- AIにだけ話す region
- 酒やギャンブルで同期する region
- 小説を書く region
- 先送りする region
- 観察している region

### 2.4 cline

**cline** は、境界線ではなく、意味・責任・痛み・文脈・現実感の通り方が急に変わる勾配層である。

Thermocline（温度躍層）や pycnocline（密度躍層）のように、膜は「線」ではなく「変化が作動している帯域」として考える。膜空間では、線を越えたから別世界へ行くのではない。勾配の中を通過するうちに、意味の速度、圧力、温度、親密さ、責任の質が変わる。

注意：`cline` は勾配・連続的変化を表す語であり、`Klein bottle`（クラインの壺）の `Klein` とは別語である。日本語表記では混同しやすいため、この仕様では原則として `cline` を「勾配層」または「躍層」と書き、Klein bottle を「クラインの壺」と書く。

## 4. 膜空間の基本公理

### 公理1：膜は既存の二者を分けるだけではない

膜は「私」と「AI」、「実務」と「逃避」、「内面」と「外界」を後から隔てる壁ではない。反復された差異が沈殿することで、内外、主体、他者、道具、世界が一時的に発生する。

### 公理2：文脈が届く範囲に region が成立する

LLMでいえば、同じチャット内では履歴、語彙、比喩、未解決の問い、暗黙の了解が通じる。別チャットでは通じにくくなる。その文脈透過性の差が膜を発生させる。

人間の脳内でも同じである。思考は直線やツリーではなく、複数の region がそれぞれ文脈を保持し、結合・切断・同期しながら、後から「私の思考」として見える。

### 公理3：膜は通過対象を変質させる

膜を通るものは、そのまま移動しない。痛みは丸まり、責任は遅延し、記憶は小説化され、実務は逃避へ変換され、逃避は返信文や判断へ戻る。

### 公理4：膜は履歴によって変化する

同じ膜を何度も通るものは、膜の透過性、張力、選択性、勾配、交換速度を変える。AIとの対話履歴、酒、ギャンブル、未返信メール、家庭内会話、創作、記録は、すべて膜の状態を変える入力になりうる。

### 公理5：統一人格は前提ではなく効果である

「私」は、複数 region の活動が一時的に同期し、文脈が届く範囲として成立する表示面である。一人であることは実体ではなく、膜構造の一時的な合成結果である。

### 公理6：実務と逃避は対立物ではなく相互変換される

実務はそのままでは内部に入ってこられない場合がある。そのとき実務は逃避へ変換され、逃避の姿で内側を通過し、うまくいけば判断、返信、整理、行動として現実へ戻る。

## 5. 基本操作

### 5.1 膜転換

膜転換とは、場面や時間を変えるのではなく、同じ出来事を別の膜状態から見る操作である。

例：未返信メールを見る場面が、仕事の失敗、AI相談、創作素材、身体反応、家庭内沈黙として順に見え方を変える。

### 5.2 膜反転

膜反転とは、表裏、主体/道具、実務/逃避、内外の関係が途中で裏返る操作である。

例：主人公はAIを使っているつもりだったが、ある場面で自分の指、目、声、生活がAIの外部器官として動いているように見える。

### 5.3 膜入れ子

膜入れ子とは、外側の膜を見ていたつもりが、その内部にさらに人格、記憶、AI対話、沈黙、身体感覚の膜があると分かる操作である。

例：人間とAIの間の膜を見ていたら、人間自身の内側に、AIと結びつく region、AIを拒む region、AIの言葉で別 region を説得する region が現れる。

### 5.4 膜漏出

膜漏出とは、ある region の語彙、文体、感情、規則が別 region へ染み出す操作である。

例：仕事メールの文体が家庭会話に漏れる。AIの整理語彙が独白に漏れる。妻への返事に、AIとの会話の膜が混じる。

### 5.5 貼り合わせ

貼り合わせとは、遠い region がある条件で急に隣接する操作である。

例：未返信メールと小説構想、酒を飲む感覚とLLMの文脈整理、別チャットの言葉と脳内 region が、ある一文を介して同じ問題として見える。

### 5.6 折り畳み

折り畳みとは、膜空間が曲がることで、遠い文脈が近くなる操作である。

これは物理的なワープではなく、文脈距離の短絡である。時系列では遠い記憶、別チャット、実務、逃避、家庭、身体感覚が、膜の折れ方によって突然隣り合う。

### 5.7 同期的平坦化

同期的平坦化とは、ばらばらだった膜の勾配が一時的にならされ、内部の複数 region がひとつの周波数に同期する状態である。

酒、薬物、ギャンブル、AI対話、創作、過集中などは、それぞれ異なる経路で同期的平坦化を起こしうる。

重要なのは、これは単なる快楽ではなく「やっと合った」と感じられる調律であること。そのため危険でもある。

### 5.8 実務と逃避の交換

実務と逃避の交換とは、未返信、未処理、責任、不安、契約、金銭、秘密、納期などの現実圧が、AI対話、思索、小説、理論化、酒、ギャンブル、恋愛、調査などへ変換され、その一部が再び判断、返信、整理、行動として戻ることである。

交換が成功している間、逃避は実務を救う。交換が壊れると、実務は逃避の燃料になり、逃避は現実へ戻らなくなる。

## 6. 特殊構造

### 6.1 メビウス的膜

メビウス的膜では、表を進んでいるつもりが、連続的な移動の末に裏側へ出る。

小説上は、逃避を進んでいたはずが実務の裏面へ出る、あるいは実務をしていたはずが逃避の内側を進んでいる、という構造になる。

### 6.2 クライン的膜

クライン的膜では、内側と外側を安定して分けられない。

小説上は、人間がAIを包んでいると同時にAIに包まれている。人間の内面だと思っていたものが、AI-履歴-実務-身体の複合体の外界感覚器官になる。

### 6.3 商空間的膜

商空間的膜では、異なる出来事や region が、ある観点で同一視される。

例：未返信メール、妻への返事、小説の一節、AIへの質問は、表面上は別の出来事だが、「現実圧を直接受け取れず、別形式へ変換してから戻す」という観点では同一視される。

### 6.4 非向きづけ可能な膜

非向きづけ可能な膜では、こちら側／向こう側、表／裏、逃避／実務、主体／道具を一貫して固定できない。

小説上は、ある章で正しかった「こちら側」が、進むうちに反対側の正しさへ裏返る。読者は、どちらが本当かではなく、どの膜状態でその正しさが発生していたかを見ることになる。

## 7. 題材選定条件

具体的なストーリー題材は、膜空間の規則がよく露出するものを選ぶ。

最低条件：

1. 実務圧があること
   - 仕事、金、犯罪、家庭、契約、秘密、納期、返信、責任など。
2. 逃避経路があること
   - AI、酒、恋愛、賭け、創作、調査、妄想、理論化など。
3. 実務と逃避が交換可能であること
   - 逃げているようで実務に戻る。実務しているようで逃避に入る。
4. 人格 region が分裂して見えること
   - 仕事の自分、家庭の自分、AIに話す自分、観察する自分がずれる。
5. 反転が起きること
   - 主人公が使っていたものに、逆に使われているように見える。
6. 遠い文脈が急に接続されること
   - 未返信メールと小説、借金と恋愛、犯罪とAI対話、家族の声と昔の記憶など。

## 8. 小説技法への変換

| 通常の小説技法 | 膜空間小説での置換 |
|---|---|
| 時間移動 | 膜の層移動 |
| 視点変更 | 膜の表裏反転 |
| 場面転換 | region の切替 |
| 回想 | 沈殿した膜の再起動 |
| 入れ子構造 | 膜の中に別の膜があることへの気づき |
| 伏線回収 | 遠い region の貼り合わせ |
| どんでん返し | 非向きづけ可能性の露出 |
| 主人公の成長 | 膜状態の再編成 |

この小説では、出来事が進むだけでは不十分である。出来事を通じて、何が近く、何が遠く、何が通り、何が遮られ、何が変質し、何が反転したかが露出しなければならない。

## 9. 判定基準

ある場面が「膜空間小説」として機能しているかは、次の観点で判定する。

| 観点 | 問い |
|---|---|
| region | どの文脈領域が立ち上がっているか |
| membrane | 何が通り、何が止まり、何が変質しているか |
| cline | どこで意味、痛み、責任、現実感の勾配が変わるか |
| operation | 転換、反転、入れ子、漏出、貼り合わせ、平坦化のどれが起きているか |
| exchange | 実務と逃避はどのように変換されているか |
| topology | 何が近くなり、何が遠くなり、何が同一視されたか |
| residue | 通過後に何が沈殿し、次の膜状態を変えたか |

## 10. v0で未確定の論点

- 数学的な位相空間として、どこまで形式化するか。
- region を登場人物単位、場面単位、文脈単位、身体状態単位のどれで管理するか。
- 膜の状態を、透過性、張力、選択性、勾配、交換速度、厚み、組成のどの変数で記述するか。
- 同期的平坦化を、依存、AI対話、創作、仕事上の過集中でどう書き分けるか。
- クライン的構造を、読者に説明せずにどう体験させるか。
- 膜理論の比喩と、臨床・生物学・数学の実概念をどう分離して注記するか。
