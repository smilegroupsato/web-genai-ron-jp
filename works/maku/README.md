# 小説『膜』

AIとの対話履歴が人間を変え、人間とAIのあいだに何枚もの膜が育ち、その膜ごと生きるようになった存在を描く小説。

## この場所の役割

ここは、**2026-07-28までに形成された旧構想 v0 に基づいて書き始めた小説『膜』v0.1 系統**の本文・断片・制作記録を保存する正本ディレクトリである。

思想研究や関連文献の整理は `research/membrane-theory/` に置き、小説本文はここで分離して管理する。

2026-08-07以降の再構想から一から書き直す別系統は、 sibling directory `../maku-reconception/` で管理する。両系統の本文は混在させない。

## 構成

- `manuscript/` — 旧構想に基づく小説本文の正本
- `fragments/` — 採否未定の場面、会話、描写断片
- `notes/` — 執筆上の気づき、読解メモ、最小限の構想記録
  - `notes/conception/` — 旧構想 v0 の復元文書
- `reviews/` — 版ごとの通読レビュー
- `versions/` — 保留・再開時の版スナップショット索引
- `archive/` — 旧稿、差し替え前の本文

## 構想

- `notes/conception/2026.08.08_01_original-conception-v0-reconstructed.md`
  - 2026-07-28時点まで遡って復元した、この系統の構想。

## 執筆原則

- 先に構造を完成させない
- 概念を説明せず、場面として書く
- 差異と反復から履歴を生み、履歴から構造を立ち上げる
- AIを単純な加害者や道具として描かない
- 主人公の状態変化を、大事件ではなく日常の蓄積として描く
- 読者に膜を理解させるのではなく、膜を通過させる
- 本文中では「膜」を理論語として早期に定義しない
