# 小説『膜』

AIとの対話履歴が人間を変え、人間とAIのあいだに何枚もの膜が育ち、その膜ごと生きるようになった存在を描く小説。

## この場所の役割

ここは、小説『膜』の本文・断片・制作記録を保存する正本ディレクトリである。

思想研究や関連文献の整理は `research/membrane-theory/` に置き、小説本文はここで分離して管理する。

## 構成

- `manuscript/` — 小説本文の正本
- `fragments/` — 採否未定の場面、会話、描写断片
- `notes/` — 執筆上の気づき、読解メモ、最小限の構想記録
- `archive/` — 旧稿、差し替え前の本文

## 執筆原則

- 先に構造を完成させない
- 概念を説明せず、場面として書く
- 差異と反復から履歴を生み、履歴から構造を立ち上げる
- AIを単純な加害者や道具として描かない
- 主人公の状態変化を、大事件ではなく日常の蓄積として描く
- 読者に膜を理解させるのではなく、膜を通過させる

## 現在地

書き出しは、深夜に未送信メールを前にAIへ相談し続ける場面から始まっている。
翌朝、AIとの対話で得た言葉が主人公の口から自然に出始め、最初の微細な状態変化が現れている。
