## 物語開始時点

| 項目 | 内容 |
|---|---|
| 表向きの問題 | 仕事、記録、複数プロジェクト、生活の整理に追われている |
| 本当の問題 | 自分の記憶、AIログ、他者の記憶、仕事上の記録のどれが「自分の正史」なのか分からなくなり始めている |
| AIを使い始めた理由 | 実務処理、調査、文章、コード、整理、相談 |
| AIなしでは触れにくくなっている現実 | 過去の自分、未処理の判断、他者との衝突、生活の手触り、身体の疲労 |
| 最初に壊れているもの | 自分が一続きの人物であるという自然な感覚 |

## 膜の発生条件

| 条件 | 内容 |
|---|---|
| 反復される行動 | AIへ相談する、ログを保存する、要約する、差分を見る、branchを切る、mainへ取り込む |
| 沈殿している履歴 | AIチャット、メール、写真、カレンダー、GitHub、古いメモ、検索履歴、他者の記憶 |
| 現実と逃避の交換 | 現実から逃げるためにAIへ話した内容が、後から現実の判断材料になる |
| 主体性が生まれる場所 | 仕事用の自分、AIへ語る自分、家族や他者の前の自分、過去ログ上の自分がそれぞれ別の局所主体として立ち上がる |
| 主体性が失われる場所 | AI要約のほうが本人より整合的に過去を語るとき |

## 身体

| 項目 | メモ |
|---|---|
| 重要な身体感覚 | 眠気、冷たさ、空腹、薬効、疲労、皮膚感覚、声、匂い |
| 身体の役割 | 無限に続く意味生成を中断する。記録へ完全に移せない局所性を残す |
| 脱身体願望 | LLMという塊へ溶けたい願望。ただし、それは自己保存なのか自己消去なのか未決着 |

## 第1章に必要な最小設定

- 主人公は、AIに「mainを直接触らず、branchを切りましょう」と言われる。
- その言葉を、最初は作業上の助言として受け取る。
- しかし「現実を壊さず、別の可能性を走らせる」ことに、本人が小さく反応する。
- 第1章では、主人公の全プロフィールを説明しない。
