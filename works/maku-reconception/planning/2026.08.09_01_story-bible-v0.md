## 作品の一文

世界に唯一の正史があるという信頼が失われた時代に、一人の人間がAI、Git、メール、写真、記憶、他者の証言へ自分の人生を分散させていく。複数の版は互いに食い違いながら存続し、どれが本当かではなく、どれが main へ採用されたかによって現実が運用される。

## 中核

- 記録が人間を保存するのではなく、記録が人間へ自己像を返し始める。
- AIは敵でも救済者でもなく、喋り出したアーカイブとして現れる。
- Gitは人生の比喩ではなく、日常作業の操作系として現れ、その構造が記憶・自己・歴史へ侵入する。
- 膜は概念説明ではなく、場面を作る規則である。
- 身体は真の自己ではなく、意味が「どうでもよくない」ものになる最後の外膜である。

## 本文で避けること

- 膜理論を登場人物に説明させすぎる。
- Git用語を人生訓として直接比喩化する。
- AI依存症もの、AI暴走もの、秘密研究所ものへ狭く閉じる。
- 主人公を作者本人の生活へ安易に一致させる。
- 設定説明だけで本文が進まない。
- 複数版の食い違いを、単なる謎解きや真相回収に還元する。

## 本文で必ず起こすこと

- 同じ出来事が複数の媒体で食い違う。
- AI要約が、後から主人公の自己記憶へ再入する。
- main と branch の違いが、仕事上の操作から人生・記憶・主体性へ染み出す。
- 身体感覚が、無限に続く意味生成を止める。
- 他者の記憶が、主人公のログ化された自己像と衝突する。
- 読者自身が、読んでいる複数版のうち何を main として扱っているかに気づく。

## 重要語の扱い

| 語 | 本文上の扱い |
|---|---|
| main | 真実ではなく、以後の運用上の正史 |
| branch | 採用されなかったが消えていない履歴 |
| commit | ある時点の変更を履歴として固定する操作 |
| diff | 変化を時間の流れではなく差分として見る面 |
| merge | 複数の履歴を、今後の運用のために取り込む操作 |
| conflict | 真実の衝突ではなく、世界間境界の編集要求 |
| 膜 | 何が通り、何が止まり、通ったものが何に変わるかを決める境界装置 |
| 身体 | 意味が局所的な切実さを持つための外膜 |
